# Art Gallery - PIEDRA

Galería de arte online con sistema de e-commerce.

## 🚀 Quick Start

### Development

```bash
# Install dependencies
npm install
cd api && npm install

# Start backend
cd api && npm run dev

# Start frontend (in another terminal)
npm run dev
```

### Production Deployment

See deployment instructions in the `develop` branch:
- Full deployment guide
- Environment variables setup
- Database migration steps

Or deploy using:
- **Frontend:** Vercel
- **Backend:** Render
- **Database:** PlanetScale
- **Images:** Cloudinary

### Environment Variables

Create `.env.local` and `api/.env` files. See `api/.env.example` for required variables.

## 📦 Tech Stack

- **Frontend:** React, TypeScript, Vite, TailwindCSS
- **Backend:** Node.js, Express, TypeScript
- **Database:** MySQL
- **Storage:** Cloudinary
- **Payments:** Stripe
- **Auth:** Firebase
