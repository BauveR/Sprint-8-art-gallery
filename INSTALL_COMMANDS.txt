🗄️ PASO 4: CONFIGURAR BASE DE DATOS MYSQL
═══════════════════════════════════════════════════════════════════

--- Opción A: Desde línea de comandos ---

# 1. Conectarse a MySQL
mysql -u root -p

# 2. Crear base de datos (en MySQL shell)
CREATE DATABASE art_gallery;
USE art_gallery;

# 3. Ejecutar schema
source api/schema.sql;

# 4. Verificar tablas
SHOW TABLES;

# 5. Salir de MySQL
EXIT;


--- Opción B: Usando script (desde terminal) ---

cd api
mysql -u root -p art_gallery < schema.sql
cd ..


--- Verificar que las tablas se crearon ---

mysql -u root -p -e "USE art_gallery; SHOW TABLES;"

Deberías ver:
  +------------------------+
  | Tables_in_art_gallery  |
  +------------------------+
  | direcciones            |
  | expos                  |
  | imagenes               |
  | obras                  |
  | ordenes                |
  | reservas               |
  | tiendas                |
  +------------------------+

🔥 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════

❌ Error: "Cannot connect to MySQL"
  → Verifica que MySQL esté corriendo: mysql.server status
  → Inicia MySQL: mysql.server start
  → Verifica credenciales en api/.env

❌ Error: "Port 3000 already in use"
  → Mata el proceso: lsof -ti:3000 | xargs kill -9
  → O cambia el puerto en api/.env

❌ Error: "Module not found"
  → Reinstala dependencias: rm -rf node_modules && npm install
  → Verifica Node.js version: node --version

❌ Error: "Firebase auth failed"
  → Verifica credenciales de Firebase en .env
  → Regenera el service account key en Firebase Console

❌ Error: "Stripe payment failed"
  → Verifica API keys de Stripe (test mode)
  → Revisa que VITE_STRIPE_PUBLISHABLE_KEY comience con pk_test_

❌ Error al subir imágenes
  → Verifica credenciales de Cloudinary
  → Revisa permisos del preset de upload
